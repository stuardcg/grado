# Walkthrough: debugging a wrong count

1. Ask the coach to print every row with its decision: `R013 → duplicate`, `R017 → rejected (date)`…
2. Read the list next to `event_rules.md`. Find one row where you disagree.
3. Tell the coach which row and which rule: "R037 should be rejected, not a duplicate, because…"
4. Fix that one rule. Run the summary again.

One row, one rule, one run. Repeat.
