# Example: what good notes look like

Here's the *shape* of good notes, for a different event (a running race). Yours will have different
content.

```markdown
## Users and moments
- Race director, at home, the week before: loads the sign-up spreadsheet.
- Volunteers at the start tent on race day: check names against the printed list.

## A registration
| Field | Required |
|---|---|
| Name | yes |
| Bib number | assigned by us |
| ... | ... |

## What can go wrong
- Same runner signs up twice with different capitalization.
- Birth date typed as 31/02.
- ...
```
