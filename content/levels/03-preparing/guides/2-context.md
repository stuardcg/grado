# Example: a prompt with context

For a *different* task (a packing list app), a four-part prompt looks like this:

```
Goal: a plan (not code) for a packing list app for weekend trips.
What I have: notes on what I pack, a list of 3 trip types.
Constraints: desktop, works offline, I'm a beginner, trip types must be easy to add.
What I want back: plan.md with a data model, screens, and 5–8 small steps.
```
