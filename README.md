# Grado

A game for building apps with AI: a player follows a project's steps, and their LLM connects to
this backend over MCP.

- [`AGENTS.md`](AGENTS.md): layout, rules and the checks to run before a commit.
- [`docs/domain/`](docs/domain/): what the product does and every call it exposes.
- [`docs/decisions/`](docs/decisions/): accepted decisions.
